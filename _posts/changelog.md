Release notes are maintained with the source. For the complete, versioned
history, see:

- [Releases on GitHub](https://github.com/sebastienrousseau/draft/releases)
- [CHANGELOG.md](https://github.com/sebastienrousseau/draft/blob/main/CHANGELOG.md)

The current release adds an Agent Client Protocol transport, a Docling reader
(`--reader docling`), per-sentence attribution with a C2PA manifest, and the
`--verify`, `--resume` and `--style` flags. Each capability is documented on
the [features](/features/) and [documentation](/documentation/) pages.
